# /learn

Capture reusable lessons after a task completes or fails repeatedly.

## Write-back rules

- Only record stable, project-specific lessons.
- Prefer updating the specialist command that owns the domain.
- Keep lessons concise and action-oriented.
- Do not store one-off debugging trivia.

## Good candidates

- repeated validation failures
- recurring architectural mistakes
- Fritzing compatibility pitfalls
- SVG coordinate or snapping gotchas
- worker communication constraints
