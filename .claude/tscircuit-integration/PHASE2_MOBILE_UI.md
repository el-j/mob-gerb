# Phase 2: Mobile-First UI and Space Optimization

## Goal
Redesign mob-gerb (and tscircuit integration surfaces) for excellent mobile device usability and efficient space usage.

## Steps
- [ ] Audit current UI/UX on mobile (identify pain points, breakpoints, touch targets, controls, overlays).
- [ ] Research best practices for mobile EDA and design tools.
- [ ] Propose new mobile-first layouts and interaction patterns (toolbars, panels, gestures, modals).
- [ ] Prototype responsive layout and controls (React, Tailwind, etc).
- [ ] Test with real mobile devices and emulators.
- [ ] Integrate tscircuit viewers/components with mobile-optimized wrappers.
- [ ] Document lessons, blockers, and reusable patterns.

## Subagent Assignments
- **react-ui**: layout, controls, breakpoints, touch/gesture logic
- **core**: data model adjustments for mobile flows
- **test**: mobile e2e and regression tests

## Reporting
- Progress and blockers tracked here and in ORCHESTRATOR.md.
- Lessons go to LEARNED.md.
